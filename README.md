# Ассемблер УВМ, вариант 6

Требуются JDK, Kotlin (kotlinc), Bash и curl. При первом запуске нужна сеть
для загрузки библиотеки org.json:json:20260814 из Maven Central.

## Язык

Программа — JSON-массив объектов. `op` — имя команды в верхнем регистре.
Операнды — неотрицательные целые JSON-числа. Лишние поля запрещены.

| op | A | B | C | D | Размер |
|---|---|---|---|---|---|
| LOAD | 28 | константа, 27 бит | адрес результата, 28 бит | — | 8 байт |
| READ | 13 | адрес результата, 28 бит | адрес указателя, 28 бит | смещение, 14 бит | 10 байт |
| WRITE | 11 | адрес источника, 28 бит | адрес указателя назначения, 28 бит | — | 8 байт |
| ADD | 9 | адрес операнда, 28 бит | адрес операнда, 28 бит | адрес результата, 28 бит | 12 байт |

LOAD: M[C] = B. READ: M[B] = M[M[C] + D].
WRITE: M[M[C]] = M[B]. ADD: M[D] = M[C] + M[B].
Здесь описана семантика команд; ассемблер их кодирует, но не исполняет.
Пример всех команд находится в examples/spec.json.

## Функции и настройки

- Operation хранит код, размер команды и ширины операндов.
- Instruction хранит команду и операнды; fields возвращает поля A–D.
- parseProgram читает JSON-массив; parseInstruction проверяет каждую команду.
- formatFields форматирует поля для проверки по спецификации.
- main принимает путь исходника, путь результата и необязательный --test.
- bash run.sh --check запускает тесты, отдельного тестового фреймворка нет.
- Все функции Kotlin описаны KDoc. Остальных настроек нет.

## Сборка, запуск и тесты

Сборка выполняется скриптом перед каждым запуском:

```bash
bash run.sh examples/spec.json build/program.bin --test
bash run.sh --check
```

На этапе 2 encode упаковывает одну команду с помощью BigInteger;
assemble объединяет команды, formatBytes форматирует байты для экрана.
Порядок байтов — little-endian, неиспользуемые старшие биты равны нулю.
Результат записывается в указанный двоичный файл. Всегда выводится число команд.
Флаг --test дополнительно выводит байты каждой команды.
Тесты проверяют поля, все четыре байтовых примера и старшие биты ADD.
Для examples/spec.json результат содержит 4 команды и занимает 38 байт.
